# カタカナ · Ficha de práctica

Página gratuita para practicar katakana desde el navegador, con diseño adaptado para usar Apple Pencil o ratón.

## Contenido
- Katakana básico (46 caracteres).
- Dakuten y handakuten.
- Combinaciones pequeñas (ゃ・ゅ・ょ en katakana: ャ・ュ・ョ).
- Combinaciones para sonidos extranjeros.
- Pistas aleatorias: katakana o romaji.
- Casillas para escribir a mano, mostrar respuestas, borrar y generar una ficha nueva.
- Impresión o guardado como PDF.

## Publicar con GitHub Pages
1. Sube `index.html` y `README.md` a la raíz de este repositorio (no dentro de otra carpeta).
2. Abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/(root)`, y guarda.
5. Cuando termine la publicación, la página estará en `https://tisifonita.github.io/katakana-practice/`.

La página no requiere instalación, inicio de sesión ni dependencias externas. Los trazos escritos se conservan solo mientras no se recargue la página.
